# Security

## Reporting

Do not open a public issue for a vulnerability or exposed secret. Contact the
repository owner privately with reproduction steps and the affected revision.

## Project rules

- Request permissions only when the related feature is used.
- Stop background location work when a trip ends.
- Keep complete tracks and original photos on the device.
- Never log tokens, verification codes, authorization headers, or precise user
  coordinates.
- Keep real service credentials outside Git and provide only `.env.example`
  templates.
